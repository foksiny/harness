# Documentation Writer for Harness

Discipline for creating crystal clear, developer-friendly technical documentation.

## Documentation Standards
1. **Audience-Centric Structure**:
   - Quickstart / TL;DR upfront for immediate productivity.
   - Conceptual architecture overview with diagrams (ASCII / Mermaid).
   - Concrete, copy-pasteable examples for common tasks.
   - Comprehensive reference tables for flags, parameters, and environment variables.
2. **Maintenance**:
   - Keep examples tested and in sync with current code signatures.
   - Explicitly list prerequisites, installation steps, and environment requirements.
